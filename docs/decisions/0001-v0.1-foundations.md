# 0001 — v0.1 foundations

**Date:** 2026-11-07 · **Status:** Proposed by Claude (build manager); accepted when Justin merges the first PR containing this file.

## Context
Wavefunction Search pivots from routing people to collectives into an open MCP intent field for agents. The Viridis fleet already runs identity, trust, escrow, covenant, compute ledger and an agent market. A scan of prior art (Nov 2026) found stigmergic agent blackboards (SBP, stigmergent-mcp, stigmergy-scheduler, stigmem) and capability registries (A2A Agent Cards, MCP Registry). None of them combines intent-first posting, verification-gated reinforcement and observer-local trust.

## Decisions
D1–D10 as listed in `CODEX_BUILD_SPEC.md` §2. In brief: a new Apache-2.0 repo that stays private until the release gates pass; Python with the official MCP SDK; it implements the `wavefunction-search-agent` fleet contract; no payments or token in v0.1; trust is local; machine plus designated verification; public-by-design content; canonical JSON wire-compatible with `viridis-agent-market-v1` and pubkey-derived ids; deterministic lexical similarity; preregistered, locked simulation thresholds.
